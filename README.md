# Various-Projects
Repository containing files for various projects I have done

Each project lives on its own branch — click through to the code, data and write-up.

| Project | Course / Term | What it is |
|---|---|---|
| [World Cup Group-Stage Advancement Model](https://github.com/Jschnizzle/Various-Projects/tree/World-Cup-Soccer-Analysis-Project) | STAT 418 · Summer 2026 | SQL joins via `sqldf` into a 366-match modeling table; Poisson, logistic and ordinal regression, trained on 1970–2006 and tested out-of-time on 2010–2022 |
| [California Housing Market & Migration Analysis](https://github.com/Jschnizzle/Various-Projects/tree/CA-Housing-Investment-Project) | STATS 421 · Nov–Dec 2025 | Python pipeline merging IRS migration flows, Census LODES, Zillow and FHFA — Census and BLS pulled live via API — into a county-level opportunity ranking |

| [Alcoholism Risk Prediction (Kaggle Competition)](https://github.com/Jschnizzle/Various-Projects/tree/Alcoholism-Prediction-Project) | STATS 101C · Fall 2023 | 70,000 records, 26 predictors, heavy missingness handled with `aregImpute`; tuned XGBoost placed 5th at 73.38% test accuracy |

| [NFL Wins Regression (Gridiron Football Analysis)](https://github.com/Jschnizzle/Various-Projects/tree/Gridiron-Football-Analysis-Project) | STATS 101A · Feb–Mar 2023 | Multiple regression on 128 team-seasons; stepwise AIC/BIC, VIF and a partial F-test reduce to turnover margin, passing offence and passing defence |
